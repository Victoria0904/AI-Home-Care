# AI-Home-Care

AI 驱动的家属远程陪诊平台 — 让不在身边的家属，也能全程安心参与患者就医。

## 在线访问

> 🔗 **访问地址**：https://victoria0904.github.io/AI-Home-Care/

支持 **PC / iOS / Android / 鸿蒙** 等多系统直接打开，无需安装、无需登录。

## 多端适配方案

| 端 | 展示方式 | 说明 |
|----|----------|------|
| **PC 端** | 完整 7 页演示 | 滚轮/方向键翻页，双端并排展示 |
| **移动端** | 家属端 V5 主界面 | 内嵌渲染，适配手机竖屏，底部可切换 |
| **鸿蒙系统** | 专项适配优化 | 修复布局错版、强制重排、禁用缩放 |

## 特性

- ✅ PC / iOS / Android / 鸿蒙 全系统兼容
- ✅ 响应式设计，自动适配屏幕尺寸
- ✅ 鸿蒙系统专项适配，解决错版问题
- ✅ 加载动画与降级方案
- ✅ 移动端底部快速切换入口
- ✅ 安全区域适配（刘海屏、全面屏）

## 技术实现

- HTML5 + CSS3 + Vanilla JavaScript
- 移动端使用 srcdoc 内嵌渲染，避免 iframe 跨域兼容问题
- 鸿蒙系统 UA 检测 + 强制重排 + CSS 修复
- GitHub Pages 静态托管
