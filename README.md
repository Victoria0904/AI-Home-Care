# AI-Home-Care

AI 驱动的家属远程陪诊平台 — 让不在身边的家属，也能全程安心参与患者就医。

## 部署说明

本项目通过 GitHub Pages 部署，内嵌了 Coze 构建的应用。

- **Coze 源应用**: https://www.coze.cn/s/mPte90Sz1ws/
- **GitHub Pages 地址**: https://victoria0904.github.io/AI-Home-Care/

## 特性

- 支持 PC 和移动端访问
- 响应式设计，自适应各种屏幕尺寸
- 加载动画与降级方案
- 移动端防误触优化

## 技术栈

- HTML5 + CSS3 + Vanilla JavaScript
- Iframe 嵌入 Coze 应用
- GitHub Pages 静态托管
