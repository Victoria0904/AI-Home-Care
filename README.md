# AI-Home-Care

AI 驱动的家属远程陪诊平台 — 让不在身边的家属，也能全程安心参与患者就医。

## 在线 Demo

**AI伴诊 · 高保真交互原型（患者端 + 家属端 + 运营安全平台）**

> 🔗 在线访问：https://victoria0904.github.io/AI-Home-Care/

无需安装、无需登录，手机浏览器 / PC 浏览器直接打开即可浏览。

## 原型内容（5 屏，可滚动翻页）

| 屏 | 内容 |
|---|------|
| 01 | 双端首页 · 第一屏（患者端 + 家属端） |
| 02 | 主诉（患者端 · 看病前把话说清 / 家属端 · 远程协同整理） |
| 03 | 就诊（患者端 · 诊中实时转写 / 家属端 · 远程在场） |
| 04 | 我的（患者端 · 家人协同与设置 / 家属端 · 账号管理） |
| 05 | 运营安全平台（主诉卡审核 · 安全兜底，如「胸痛胸闷」→ 提示拨打 120） |

## 操作方式

- **PC**：滚轮 / 方向键 / 数字键 `1-8` 翻页，右侧圆点可直接跳转
- **移动端**：上下滑动翻页，右侧圆点可直接跳转

## 本地运行

本原型为单个自包含 HTML 文件（无外部依赖，图片已内嵌），任选其一：

1. 直接双击打开 `index.html`
2. 或启动本地静态服务：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
